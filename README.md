# Kassenapp 🛒

Willkommen bei **Kassenapp** – einer effizienten und benutzerfreundlichen Anwendung.

## 📝 Projektbeschreibung
Kassenapp ist eine Android-basierte Anwendung, die es ermöglicht, Produkte zu verwalten, Verkäufe in Echtzeit abzuwickeln und einen Überblick über den aktuellen Tagesumsatz zu behalten. Die App ist auf Schnelligkeit und intuitive Bedienung optimiert.

## ✨ Hauptfunktionen

### 1. Produktverwaltung
*   **Artikel anlegen:** Schnelles Hinzufügen von Produkten mit Name, Preis.

### 2. Verkaufsprozess (Checkout)
*   **Warenkorb-System:** Produkte einfach auswählen und in einen virtuellen Warenkorb legen.

### 3. Berichterstattung & Analyse
*   **Umsatzübersicht:** Siehe, wie viel Umsatz pro Tag generiert wurde.
